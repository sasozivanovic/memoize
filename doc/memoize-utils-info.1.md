# NAME
memoize-utils-info - Print out the /MMIZ_Record of the PDF catalog


# SYNOPSIS
**memoize-utils info** [*OPTIONS*] *document.pdf*


# DESCRIPTION

**memoize-utils** is a script accompanying Memoize, a TeX package which allows
the author to reuse the results of compilation-intensive code such as TikZ
pictures.  This manual page documents command **info** of this script.

**memoize-utils info** writes the information contained in */MMIZ_Record* of
  the PDF catalog of *document.pdf* in human-readable form to standard output.

# OPTIONS

This command has no options.
